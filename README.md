# Medora

Android study app for medical students (Kotlin + Jetpack Compose + Room).

- Import lectures (TXT), write notes, make flashcards and quizzes.
- FSRS spaced repetition and progress tracking.
- Export to PDF and PPTX.
- Optional AI with your own Gemini / OpenRouter keys (no keys in this repo).
- Works offline for the core features. Arabic and English with RTL.
- Backup and restore from Settings.
